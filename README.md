# CodeSplash AI

CodeSplash is a complete AI Coding Platform by CodeSplash AI. It is an all-in-one agentic engineering platform that brings parallel AI agents, Git, editor, terminal, browser, API, database, command center, and operational tooling into one application.

This repository is the public release surface for CodeSplash AI.

## Product Model

- Desktop application for macOS, Windows, and Linux
- Parallel AI agents and a command center for multi-repo engineering workflows
- Lightweight backend only for license management, billing, and related account operations
