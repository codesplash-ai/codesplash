## Features

### Visual Git Operations
Stage, unstage, commit, and manage branches with an intuitive interface. See diffs side-by-side with syntax highlighting. Handle stashes, tags, and all core git operations effortlessly.

<!-- Add screenshot: Staging area with diff view -->

### Advanced Git Tools
**Interactive rebase**, **3-way merge editor**, **GitFlow** workflow support, and **worktrees**—power user features that make complex git operations simple. No more memorizing git commands.

<!-- Add screenshot: Interactive rebase interface -->

### GitHub Integration
Manage **pull requests**, **issues**, and **GitHub Actions** directly from the app. Create PRs, review code, merge branches, and monitor workflows. Multi-account support with secure OAuth authentication.

<!-- Add screenshot: Pull request view -->

### Built-in Code Editor
Full-featured **Monaco Editor** with syntax highlighting, multi-tab support, and split view. Edit files, view changes, and navigate your codebase without switching apps.

<!-- Add screenshot: Editor mode with file explorer -->

### Integrated Terminal
Complete terminal emulator with **multiple tabs**, PTY support, and shell integration. Run commands, scripts, and git operations without leaving the app.

<!-- Add screenshot: Terminal with multiple tabs -->

### AI Assistant
Three powerful modes: **Agent** (AI can execute git commands and read files), **Ask** (chat about your code), and **Edit** (AI-assisted code changes). Bring your own API keys for Claude, ChatGPT, or Gemini.

<!-- Add screenshot: AI chat interface -->

### Beautiful Themes
Light and dark modes with **10+ built-in themes** including GitHub, Dracula, and more. Create and customize your own themes. Optional window transparency and vibrancy effects.

<!-- Add screenshot: Theme customization -->

### Built for Large Repos
**Virtual scrolling** handles repositories with 10,000+ commits smoothly. Fast performance even with massive commit histories and large file trees.

## FAQ

<details>
<summary><strong>What is AI Git?</strong></summary>

AI Git is a desktop Git client that combines powerful git tools (interactive rebase, merge editor, GitFlow) with GitHub integration and an AI assistant. It's designed as a modern replacement for Tower and other Git GUIs.
</details>

<details>
<summary><strong>Is AI Git really free?</strong></summary>

Yes! The free version includes all core git operations, GitHub integration, AI chat, code editor, terminal, and built-in themes. Pro features like interactive rebase, 3-way merge editor, and GitFlow are a one-time $49 purchase.
</details>

<details>
<summary><strong>What's included in Pro?</strong></summary>

Pro unlocks advanced features: interactive rebase, 3-way merge editor, GitFlow workflow, worktrees, custom themes, and window effects. It's a one-time purchase with a 14-day free trial.
</details>

<details>
<summary><strong>How does the AI assistant work?</strong></summary>

AI Git uses a BYOK (Bring Your Own Key) model. Add your API keys from Claude (Anthropic), ChatGPT (OpenAI), or Gemini (Google), and the AI can help you with git operations, answer questions about your code, or assist with editing.
</details>

<details>
<summary><strong>Is my code private?</strong></summary>

Absolutely. AI Git runs locally on your machine. Your code never leaves your computer except when you push to remote repositories or send context to AI providers (using your own API keys).
</details>

<details>
<summary><strong>Does it work offline?</strong></summary>

Yes! All local git operations work fully offline. GitHub integration and AI features require internet connectivity.
</details>

<details>
<summary><strong>What git hosting services are supported?</strong></summary>

GitHub is fully supported with PR management, issues, and Actions. GitLab and Bitbucket support are planned for future releases.
</details>

<details>
<summary><strong>How do updates work?</strong></summary>

AI Git checks for updates automatically and prompts you to install new versions. Updates are downloaded from GitHub Releases and installed seamlessly.
</details>

<details>
<summary><strong>Can I use AI Git with any repository?</strong></summary>

Yes! AI Git works with any git repository—local or remote. It's compatible with repositories hosted on GitHub, GitLab, Bitbucket, or any other git hosting service.
</details>

<details>
<summary><strong>How do I get a refund for Pro?</strong></summary>

We offer a 14-day free trial so you can try Pro features before purchasing. If you're not satisfied after purchase, contact support within 30 days for a full refund.
</details>
